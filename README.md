# VR Extinct Animal Museum

A one-month VR prototype where users explore a small virtual museum featuring extinct animals and their conservation lessons.

## Project Teams

- XR Developers
- 3D Artists
- Storytellers
- Researchers

## Unity Version

Use the same Unity version as the project creator.

## Important Rules

1. Always pull before working.
2. Do not edit Museum_Main.unity unless assigned.
3. Use prefabs for exhibits.
4. Commit small changes with clear messages.
5. Push after committing.
6. Do not commit Library, Temp, Obj, Builds, or Logs folders.
7. Keep assets optimized for VR.

## Folder Structure

Main project files are inside:

Assets/_Scenes/

## Current Prototype Scope

- 1 small VR museum
- 3 extinct animal exhibits
- 1 basic interaction per exhibit
- final reflection room
